# Student Data Management System

## Project Overview
The Student Data Management System is a console-based application developed using C programming. It is designed to manage student information efficiently, including roll numbers, names, and percentages.

This project uses a singly linked list and file handling to store, manage, and organize student records.

## Technologies Used
- C Programming
- Structures
- Pointers
- Singly Linked List
- File Handling
- Dynamic Memory Allocation

## Features
- Add new student records
- Display all student records
- Delete student records using roll number or name
- Modify existing student details
- Sort student records by name in ascending order
- Sort student records by percentage in descending order
- Reverse the student records list
- Delete all student records
- Save student records to a file
- Load previously saved student records from a file

## How to Compile and Run

### Step 1: Compile the program

```bash
gcc student.c -o student
```

### Step 2: Run the program

**Windows:**
```bash
student.exe
```

**Linux:**
```bash
./student
```

## File Handling
The program uses a binary file named `student.dat` to store student records permanently. Previously saved records can be loaded when the program runs.
